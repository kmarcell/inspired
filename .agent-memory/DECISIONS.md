# Architectural Decisions (ADRs) - Inspired Yoga Platform

> **Agent Memory Template**: This file records architectural and technical decisions made during implementation, particularly in autonomous mode (`--yolo` or `--dangerously-skip-permissions`).
> Keep entries concise, high-signal, and focused on non-trivial choices against alternatives.

## Template Entry

### [ADR-YYYYMMDD-01] Title of Decision
- **Context:** Brief 1-2 sentence problem statement and constraints.
- **Alternatives Considered:**
  1. *Option A:* Description (Trade-off / Why discarded).
  2. *Option B:* Description (Trade-off / Why discarded).
- **Chosen Decision & Rationale:** Why the chosen approach was selected.
- **Impacted Files:** [`path/to/file.ts`](file:///absolute/path/to/file.ts)
- **Status:** Proposed | Accepted | Superseded
- **Timestamp:** YYYY-MM-DDTHH:MM:SSZ
